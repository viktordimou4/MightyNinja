# MightyNinja 🥷

**Heavy Ninja Action - Gang Edition**

Welcome to MightyNinja, an intense ninja combat simulator featuring a gang of mighty warriors with devastating heavy attacks and special abilities!

## Features

- 🥊 **Heavy Strike**: Devastating power attacks dealing massive damage
- 🌙 **Shadow Assault**: Stealthy strikes from the darkness
- 🔥 **Berserker Fury**: Ultimate multi-hit combo attack
- 🧘 **Stealth Recovery**: Meditate to restore energy
- ⚔️ **Ninja Gang System**: Build your own gang of specialized warriors

## Quick Start

Run the heavy ninja action simulator:

```bash
python3 mighty_ninja.py
```

## Ninja Abilities

Each ninja has three core attributes:
- **Strength**: Increases damage of heavy strikes and fury attacks
- **Agility**: Improves dodge chance and shadow assault damage
- **Stealth**: Enhances stealth-based attacks and energy recovery

## Heavy Action Moves

1. **Heavy Strike** (20 energy): A powerful direct attack based on strength
2. **Shadow Assault** (30 energy): Combines stealth and agility for a devastating strike
3. **Berserker Fury** (50 energy): Unleash 3 consecutive heavy strikes
4. **Stealth Recovery**: Meditate to recover energy based on stealth stat

## The Gang

The default gang includes:
- **Shadow Master**: High stealth and agility specialist
- **Iron Fist**: Maximum strength heavy hitter
- **Swift Blade**: Balanced agility fighter
